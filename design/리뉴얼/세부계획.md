## 문서 구성과 설계 기준

메인 메뉴별로 Create / My Rings / Learn을 나눈다. 현재 구체화 대상은 **Create**다. 최신 제안은 아래 A0의 상단 상황별 도구막대 구성이다. 파일을 늘리지 않고 이 문서 안에서 메뉴별로 구분한다.

- 사용자 요청은 요구사항으로, 구체적인 배치·동작은 설계 제안으로 구분한다.
- 현재 Rings는 기능과 데이터 동작을 파악하는 참고 자료다. 기존 UI의 위치·크기·형태를 유지할 필요는 없으며 새로 디자인할 수 있다.
- 기능을 찾기 쉽게 재배치하고, 불필요한 설정 노출을 줄인다. UI 정리만을 이유로 기존 기능이나 저장 데이터를 삭제하지 않는다.
- 이번 요청의 ‘굵기 삭제’는 오토필드의 글자 굵게 버튼 제거로 반영한다. 공유 글자 설정을 쓰는 일반 텍스트에도 동일한 UI를 적용하는 안을 제안한다. 선·도형의 선 두께는 유지한다.

## A. Create — 새 작업과 제작

### A0. 최신 화면 제안 — 넣기는 왼쪽, 꾸미기는 위쪽

사용자의 상단 텍스트 바 아이디어를 확장해 **선택한 요소에 따라 바뀌는 도구막대**를 편집 영역 상단에 둔다. 기존의 긴 좌측 설정 목록을 단순히 재배열하는 대신, 탐색·삽입과 꾸미기를 공간적으로 분리한다. 이는 검토용 제안이며 구현 확정은 아니다.

`상단 전역 바: Rings / 작업 이름 / 저장 상태 / 실행 취소 / 인쇄 준비`

`좌측: 도구 → 넣을 내용·종류·자료 | 편집 영역 상단: 선택 대상의 꾸미기`

`좌측 하단: 작업 팔레트          | 중앙: 페이지와 페이지별 관리 버튼`

#### 화면 영역별 책임

- **좌측 도구 패널**: 무엇을 넣을지 찾고 선택한다. 템플릿·이미지는 미리보기, 요소는 모양, 오토필드는 날짜 연결과 표시 형식에 집중한다.
- **상단 상황별 바**: 글꼴·크기·정렬, 선 두께·선 모양, 이미지 크기 등 선택 대상의 외형을 조절한다. 캔버스 바로 위에서 위치를 유지한다.
- **작업 팔레트**: 좌측 하단에 유지한다. 상단에는 필요할 때 ‘글자 A’, ‘선 기본’, ‘채움 B’ 같은 적용 대상만 표시하고 색상 편집기를 중복 배치하지 않는다.
- **페이지 설정**: 문서 전체 또는 페이지 자체의 설정이므로 왼쪽에 둔다. 요소 꾸미기와 혼동하지 않는다.
- **페이지 메뉴**: 복제·여러 장 복제·저장·삭제는 해당 페이지 가까이에 유지한다.

#### 바의 상태

| 선택 상태 | 상단에 보이는 것 | 펼쳤을 때 |
|---|---|---|
| 필드·일반 글자 | 글꼴 / 크기 pt / 가로 정렬 / 색상 역할 | 간격: 줄간격·자간 mm, 배치: 세로 정렬·회전 |
| 달력 | 글꼴 / 자동 맞춤·크기 / 색상 역할 | 달력 행 간격·자간, 적용 대상은 전체를 기본으로 검토 |
| 선 | 두께 mm / 실선·파선·점선 / 선 색상 역할 | 배치·회전 |
| 도형·표 | 테두리 두께·모양 / 채움 / 색상 역할 | 모서리·불투명도; 표에서 지원하지 않는 속성은 숨김 |
| 체크박스 | 아이콘 크기 mm / 테두리 두께 / 색상 역할 | 배치 |
| 이미지 | 가로·세로 mm / 비율 유지 / 교체 | 회전·배치 |
| 선택 없음 | 선택 안내 또는 새로 만들 요소의 기본 스타일 | 전역 기능을 억지로 채우지 않음 |
| 혼합 선택 | 공통으로 적용 가능한 속성만 | 혼합 값 표시, 변경한 속성만 반영 |

최상단 작업 바와 상황별 바는 역할을 구분한다. 텍스트 설정은 왼쪽과 위쪽에 중복 노출하지 않는다. ‘간격’ 버튼을 열면 줄간격과 자간을 함께 조절하되 모든 숫자 칸을 항상 펼치지는 않는다.

#### 추가 아이디어 — 검토용

1. **글자 스타일 보관**: ‘섹션 제목’, ‘작은 캡션’처럼 글꼴·크기·간격·색상 역할을 저장해 반복 페이지에서 재사용한다. 문서 전체 변경과의 연결 범위는 별도 검토한다.
2. **모양 복사**: 내용이나 날짜 연결을 바꾸지 않고 선택 요소의 꾸미기만 다른 요소에 적용한다. 기존 기능으로 간주하지 않으며 2차 우선순위다.
3. **형식 칩의 실제 날짜 미리보기**: 월·일·주·요일을 고르면 현재 페이지 날짜를 예시로 사용해 선택 직후 결과를 예측할 수 있게 한다.
4. **페이지 추가의 작은 선택 메뉴**: 빈 페이지 / 템플릿에서 / 날짜로 만들기를 페이지 아래 한 진입점으로 모은다.
5. **복제 시 두 가지 목적 구분**: 한 번 누르는 복제는 내용 그대로, ‘여러 장 만들기’에서는 동일 복제와 날짜 진행을 분명히 구분한다.
6. **선택 범위를 짧게 표시**: ‘날짜 글자 1개’, ‘메모 양식 12페이지 공통’처럼 실제 수정 범위를 바 가까이에 보여준다. 공통 수정 연결이 확정된 경우에만 후자를 제공한다.

#### 스케치 읽는 법과 한계

대화에 제공한 화면 스케치는 왼쪽 여섯 메뉴를 전환하면 해당 삽입 패널과 상단 바 구성이 바뀐다. 오토필드의 종류·형식과 일부 글자 크기·자간·색 적용은 미리보기로 확인할 수 있다. 페이지 추가·인쇄·업로드 등은 다음 동작을 안내하는 구성 예시이며 실제 편집 기능을 실행하지 않는다. A5와 날짜는 설명용 예시다. 최종 미감·모바일 편집·정확한 인쇄 치수는 검증 대상에 포함하지 않았다.

좁은 화면에서는 중요 도구를 남기고 나머지를 더보기로 접는다. 스케치는 비교를 위해 패널을 위아래로 배치하지만 이를 모바일 제품의 최종 설계로 확정하지 않는다.

### A1. 전체 화면과 진입

- 상단: 작업 이름, 현재 규격, 인쇄 준비 액션.
- 좌측: 도구별 자료·내용 선택과 페이지 설정.
- 중앙: 페이지가 세로로 이어지는 편집 영역.
- 각 페이지: 페이지 정보와 관리 메뉴, 페이지 추가 진입점.
- 좌측 하단: 공통 색상 관리 영역을 두는 방향.

설계 제안: 페이지 목록은 상시 패널 대신 필요할 때 여는 ‘페이지 한눈에 보기’로 제공한다. 별도의 오른쪽 설정 패널을 기본 구조에 추가하지 않는다.

좌측 메뉴 재구성의 우선 대상은 **큰 탭 이름이나 개수보다 탭 내부 세부 항목의 순서·그룹·표현**이다. 앞서 논의한 큰 탭 축소안은 확정안으로 취급하지 않는다.

기존 좌측 도구는 기능 범위를 파악하는 출발점이다. 새 UI는 아래처럼 구성하는 안을 검토한다.

- 기본 규격은 개인화 질문에서 정한 사용자의 주 사용 다이어리 크기를 따른다.
- 상단은 작업 이름·저장 상태·규격·실행 취소/다시 실행·인쇄 준비로 정돈한다. 저장 상태 표시는 설계 제안이다.
- 좌측 도구의 후보 순서는 페이지 설정 → 템플릿 → 요소 → 텍스트 → 이미지 → 오토필드다. 최종 명칭과 순서는 시안 검토 후 정한다.
- 선택은 기본 조작으로 제공하고, 선택 대상에 따라 상단 바가 해당 꾸미기 속성으로 바뀐다. 왼쪽은 필요한 내용 설정을 보여준다. 상시 독립 Select 탭 유지 여부는 시안에서 검토한다.
- 속성 패널 상단에 ‘새 요소에 적용 / 선택한 1개에 적용 / 선택한 3개에 적용’을 구분해 표시한다.
- 인쇄용 용지 설정은 제작 도구 목록에서 분리해 인쇄 준비에 둔다.

### A3. 모든 도구에 적용할 속성 UI

- 흐름은 **무엇을 넣는가 → 내용 → 모양 → 간격·배치**로 통일한다. 앞의 두 단계는 왼쪽, 모양과 간격·배치는 상단 바에서 처리한다.
- 입력칸 위나 옆에 라벨을 항상 표시한다. 단위만 보이는 ‘pt’, ‘mm’, ‘100%’ 입력을 만들지 않는다.
- 숫자는 직접 입력과 작은 증감 버튼을 함께 제공한다. 숫자·단위는 한 입력 그룹으로 묶는다.
- 글자 크기는 pt, 줄간격·자간·실제 치수는 mm로 표시하는 방향이다. 아래 값은 배치 예시이며 기본값 확정이 아니다.

`글자 크기 [10 pt]    줄간격 [4.5 mm]    자간 [0 mm]`

- 좁은 패널에서는 글자 크기를 한 줄, 줄간격·자간을 다음 줄에 배치한다.
- 줄간격은 줄 기준선 사이 거리, 자간은 글자 사이 추가 간격으로 설명한다. 한 줄 텍스트에는 줄간격을 비활성화하거나 고급 항목으로 접는다.
- 정렬은 라벨 있는 아이콘 그룹, 표시 여부는 체크/스위치, 상호 배타적 종류는 작은 전환 버튼을 사용한다.
- 복수 선택에서 값이 다르면 ‘혼합’으로 표시하며, 사용자가 변경한 속성만 적용한다.
- 색상 편집은 좌측 하단 팔레트로 모으되 적용 대상이 글자/선/채움 중 무엇인지 표시한다.
- 입력 오류는 해당 칸에서 안내하고, 숫자를 입력하는 중 포커스를 빼앗지 않는다.

### A4. 오토필드 — 우선 설계 대상

#### A4.1 현재 구조에서 해결할 문제

- 현재 Field 서식 15개가 날짜·요일·월·주차 구분 없이 한 목록에 들어 있다.
- 예시 ‘3’과 ‘15’, ‘월’은 종류를 먼저 알지 못하면 의미가 모호하다.
- 필드의 값 순서는 내부 기준인 0부터 표시된다. 사용자는 ‘첫째 날짜’로 이해하는 편이 쉽다.
- 현재 필드는 일반 텍스트 설정을 공유한다. pt 글자 크기와 mm 줄간격은 있으나 일반 텍스트/필드용 자간 속성은 확인한 모델과 컨트롤에 없다.
- 달력에는 이미 mm 자간이 있다. 달력의 글자 크기와 행 간격은 비율 방식이어서 텍스트와 표현이 다르다.
- 필드 설정의 안내는 인쇄 때 값이 채워지는 구조를 전제로 한다. 새 제작 흐름에서는 실제 날짜를 편집 중 보여줘야 한다.

#### A4.2 패널 공통 구조

맨 위의 큰 Calendar / Field 버튼을 작은 ‘달력 / 필드’ 전환으로 정리한다. 그 아래에는 선택한 종류의 내용만 표시한다. 한쪽을 선택한다고 이미 놓인 반대 종류의 요소를 변환하지 않는다.

미선택 상태는 새로 넣을 요소 설정, 선택 상태는 기존 요소 수정임을 표시한다. 사용자에게 내부 자리표시 코드를 기본 노출하지 않는다.

#### A4.3 필드: 종류와 표시 형식

사용자 요청: 월·일·주·요일을 더 이해하기 좋은 UI로 구성한다.

| 종류 버튼 | 표시 형식 예시 — 기존 기능 보존 | 새 UI |
|---|---|---|
| 월 | 3 / 3월 / MAR / March | 예시 칩을 골라 적용 |
| 일 | 15 / 3/15 / 3월 15일 / 2027-03-15 | 일만 표시와 전체 날짜 표현을 함께 탐색 |
| 주 | 11주차 / W11 / Week 11 | ‘주차’라는 설명과 예시 표시 |
| 요일 | 월 / 월요일 / Mon / Monday | 한글·영어 결과를 직접 보고 선택 |

선택 순서: 왼쪽의 **종류 → 표시 형식 → 어떤 날짜를 사용할지**, 이후 상단 바의 **글자 모양**.

- 예시 칩은 가능하면 현재 미리보기 날짜로 갱신한다.
- ‘주’는 현재 구현상 연중 주차다. 1월 1일부터 7일씩 계산하는 기존 규칙을 ISO 주차나 월별 주차로 조용히 바꾸지 않는다. 다른 주차 기준 지원 여부는 미정이다.
- 단독 연도 필드, 자유 서식 조합 등 기존 목록에 없는 형식은 신규 기능으로 별도 검토한다.
- ‘0번째’ 대신 ‘이 페이지의 첫째 날짜 / 둘째 날짜…’처럼 보여주고 내부 순번과 연결한다.
- 같은 날짜의 월·일·요일 필드를 따로 놓으면 모두 같은 날짜에 연결할 수 있어야 한다. 배치할 때마다 날짜를 무조건 증가시키지 않는다.
- ‘다음 날짜로 이어 배치’는 별도 선택으로 제공하는 안을 검토한다. 위클리처럼 서로 다른 날짜가 필요한 경우에 사용한다.

필드 화면의 좌측·상단 배치 예시:

`[달력 | 필드]`

`종류     [월] [일] [주] [요일]`

`표시     [15] [3/15] [3월 15일] [2027-03-15]`

`날짜 연결  [이 페이지의 첫째 날짜 ▾]   미리보기: 3/15`

`상단 바: 글꼴 [선택 ▾]   글자 크기 [10 pt]`

`상단 간격 팝오버: 줄간격 [4.5 mm]  자간 [0 mm]`

`정렬 [왼쪽 / 가운데 / 오른쪽]   배치 [펼치기]`

#### A4.4 달력: 내용과 표현 분리

1. **기준 월**: 페이지에 연결된 연·월과 실제 미리보기. 여러 달 생성은 별도 액션.
2. **달력 구성**: 시작 요일, 요일 언어, 이전·다음 달 표시.
3. **제목**: 자동 / 직접 입력 / 숨김을 명시적으로 구분. 빈 입력의 의미에 의존하지 않는다.
4. **글자 — 상단 바**: 글꼴과 글자 크기. 크기는 ‘자동 맞춤 / 직접 지정 pt’ 방식을 제안한다.
5. **간격 — 상단 팝오버**: 달력의 주 행 간격과 자간. mm 입력을 제안하되 제목·요일·주 행의 간격을 무엇으로 조정할지 시안과 출력 결과로 검토한다.

현재 크기 배율·행 간격 배율을 숫자만 pt·mm로 치환하면 안 된다. 기존 달력의 상자 크기와 실제 배치를 바탕으로 환산하거나 기존 자동 동작을 유지해야 한다. 직접 지정 시 넘침을 알려야 한다.

달력 전체 색상 변경은 공통 팔레트와 연결한다. 제목·요일·특정 날짜를 각각 선택해 색을 바꾸는 기능은 아직 사용 범위가 확정되지 않았다. 확정 기능으로 표시하지 않는다.

#### A4.5 굵기·단위·자간 요구사항

- 오토필드의 글자 굵게 버튼은 제거한다.
- 일반 텍스트도 동일한 글자 패널을 쓰는 것을 제안한다. 과거 문서의 bold 값을 지워 외형을 바꾸는 것은 별도 문제이며 보존 방식 검토가 필요하다.
- 필드와 일반 텍스트에 자간 mm 설정을 추가한다. 달력의 기존 자간도 같은 라벨·입력 스타일로 통일한다.
- pt는 글자 크기, mm는 줄간격·자간임을 라벨과 함께 표시한다.
- 자간은 화면 표시뿐 아니라 선택 상자·텍스트 측정·줄바꿈·저장/재열기·PDF에도 일관되게 적용해야 한다.
- 음수 자간 허용 범위, 입력 증감 폭, 기본값과 최대·최소값은 구현 전 결정한다.

#### A4.6 날짜로 페이지 만들기와 개별 수정

##### 사용자 요청

Print에서 날짜가 채워진 결과를 확인하고 색상 등을 개별 수정해야 하는 현재 흐름을 단순화한다. 여러 페이지 제작과 수정이 제작 화면 안에서 이어져야 한다.

##### 설계 제안

1. 페이지에 날짜·달력을 배치한다.
2. 기간과 페이지당 날짜 진행 규칙을 지정한다.
3. 생성될 페이지 수와 날짜를 확인한다.
4. 실제 날짜가 들어간 페이지들을 제작 화면에 생성한다.
5. 특정 페이지나 공통 디자인을 수정한다.

예: M5 데일리 디자인 → 10월 기간 지정 → 31페이지 생성 → 특정 날짜의 글자색 수정 → 인쇄 준비.

공통 디자인 변경에는 ‘이 페이지만 / 같은 양식으로 만든 페이지 전체’와 같은 적용 범위를 검토한다. 이 범위 선택을 모든 조작마다 반복적으로 묻지 않도록 UI를 설계해야 한다.

##### 결정 (2026-09-27)

1. **개별 수정은 고친 요소 하나만 원본에서 분리한다.**
   - 예: 10/1~10/14를 생성한 뒤 10/5의 날짜 필드 색만 바꾼다. 이때 분리되는 것은 그 필드 하나다.
   - 10/5 페이지의 나머지 요소는 원본 양식을 계속 따른다. 원본을 고치면 10/5에도 반영된다.
   - 원본을 처음부터 다시 만들고 싶으면 생성된 페이지를 지우고 다시 생성한다. 이 경로는 별도 기능 없이 가능하다.
   - 현재 코드는 페이지 단위로 분리한다(`pageOverrides`: 한 곳을 고치면 그 페이지 전체가 분리). 리뉴얼에서 요소 단위로 바꾼다.
2. **편집 화면의 자동필드는 실제 값으로 보인다.**
   - 현재의 `⟨+D0⟩` 같은 자리표시 대신 `10/1`처럼 선택한 서식이 적용된 실제 글자를 보여준다.
   - 생성된 각 페이지는 자기 날짜를 표시한다(10/1, 10/2 …).

##### 이 결정으로 새로 정해야 할 것

- **원본 양식에 보일 날짜**: 기간을 정하기 전의 원본 페이지에 어떤 날짜를 보여줄지 정해야 한다. 후보는 오늘 날짜, 또는 기간을 정한 뒤 첫 날짜다.
- **분리되는 범위**: 10/5 필드의 색만 바꾼 경우 날짜 값은 계속 자동인지, 글자 자체를 고치면(예: ‘10/5 생일’) 고정 글자가 되는지 정해야 한다.
- **자리표시 직접 입력**: 현재는 글자 안에 `<+D0>`를 직접 쳐서 필드를 만드는 기능이 있다(`FIELD_PATTERN`). 실제 값 표시로 바꾸면 이 입력 방식을 유지할지 정해야 한다.
- **필드 구별**: 자리표시가 사라지면 일반 글자 ‘10/1’과 자동필드 ‘10/1’이 똑같이 보인다. 자동필드임을 표시하는 방법(선택 시 표시, 옅은 밑줄 등)이 필요하다.

미정:

- 공통 디자인과 개별 수정의 연결 방식 — 요소 단위 분리로 결정(위 참조). 공통 수정의 적용 범위 UI는 남음.
- 기간 변경·재생성 시 개별 수정 보존 방식.
- 날짜가 제거되거나 순서가 바뀔 때 수정 내용의 귀속 기준.
- 자동 생성된 묶음 사이에 다른 페이지를 삽입하는 동작.
- 공통 색상 팔레트 변경과 페이지 한정 변경의 관계.

### A5. 페이지 설정 — 기존 Insert

설계 제안 순서:

1. **규격**: 사용자의 기본 규격을 미리 적용. 규격 선택, 가로·세로 mm. 기본 규격 변경과 현재 작업 크기 변경은 구분.
2. **바탕**: 도트 / 그리드 / 가로줄 / 세로줄 미리보기 버튼. 간격과 칸 수는 연결된 값임을 표시.
3. **여백**: 최소 여백과 실제 계산된 여백을 구분. 끝까지 채우면 불필요한 최소 여백 입력 숨김.
4. **타공**: 구멍 수, 균등/묶음 배치, 해당할 때만 묶음 간격, 안전영역.
5. **안내**: 도트·타공 화면 표시, 등분 안내. ‘화면에만 표시’와 ‘출력에 포함’을 분리.

뒷면이 없을 때 도트만 출력하는 옵션은 인쇄 준비로 이동한다. 상세 계산 결과는 접은 ‘치수 확인’에 배치한다.

### A6. 템플릿 탐색과 저장

추가 UI 제안: 기본 템플릿 / 내 템플릿 전환 → 현재 규격으로 필터 → 미리보기 → 페이지 추가. 새 양식 삽입이 현재 페이지를 자동 덮어쓰지 않도록 한다. 다른 규격을 가져올 때의 변환은 미정이다.

#### 사용자 요청

만든 페이지 구성을 템플릿으로 저장하고 My Rings에서 관리한다. 단면·양면을 선택할 수 있는 구성을 고려한다.

#### 설계 제안

- 페이지 더보기 또는 여러 페이지 선택 상태에서 ‘내 템플릿으로 저장’ 제공.
- 저장할 이름, 포함 페이지, 앞뒤 구성을 확인.
- 저장 단위: 한 면 / 앞뒤 한 쌍 / 여러 페이지 묶음.
- 원래 작업은 유지하고 재사용할 구성만 따로 보관.
- My Rings의 ‘내 템플릿’과 편집기의 템플릿 패널에서 접근.
- 자동필드는 디자인·규칙을 유지하고 재사용 시 기간을 정하도록 검토.

미정: 원본 템플릿 수정의 기존 작업 반영 여부, 다른 규격으로 추가할 때 처리, 고정 날짜 저장 옵션, 템플릿 이름 중복과 버전 관리.

### A7. 요소 — 선·도형·표·체크박스

왼쪽에 모양 미리보기 타일을 두고 아래 속성은 선택 후 상단 바에 표시한다. 큰 세로 버튼을 나열하지 않고 선·도형·표·체크박스를 한눈에 비교하게 한다.

- 첫 줄에서 종류를 고르고, 종류별 미리보기 아이콘을 통일한다.
- **선**: 두께 mm → 실선/파선/점선. 색상은 하단 팔레트의 선 색에 연결.
- **도형**: 모서리 모양 → 테두리 두께·선 모양 → 채움 여부·불투명도. 채움이 없으면 관련 설정 숨김.
- **표**: 기존 격자 기반 생성·분할 동작을 보존하고, 테두리/내부 선의 공통 두께·선 모양과 외곽 모서리를 정리한다. 행·열 직접 입력이나 개별 셀 편집은 신규 제안이며 현재 지원으로 간주하지 않는다.
- **체크박스**: 아이콘 미리보기 → 아이콘 크기 mm → 테두리 두께. 선택한 모양이 분명하게 보이게 한다.
- 선 두께는 글자 굵게와 다른 속성으로 유지한다.

### A8. 텍스트

왼쪽은 제목·본문 추가와 저장한 글자 스타일 탐색에 집중한다. 글자 스타일 보관은 신규 제안이다. 아래 꾸미기는 상단 바와 팝오버로 옮긴다.

설계 제안: 글꼴 → 글자 크기 pt → 가로 정렬 → 줄간격·자간 mm → 펼친 배치 설정의 세로 정렬·회전 순서.

일반 텍스트는 직접 입력에 집중한다. 자동필드로 바꾸기는 상시 체크박스 대신 보조 메뉴로 이동하는 안을 검토한다. 변환 시 현재 글자와 날짜 연결이 어떻게 바뀌는지 보여준다. 글꼴 선택에는 My Rings의 등록 글꼴을 사용하고 관리로 연결한다.

### A9. 이미지

왼쪽은 이미지 썸네일 목록과 추가, 상단은 선택 이미지의 크기·비율·교체·회전으로 역할을 나눈다.

설계 제안: 이미지 미리보기 목록과 추가 → 선택 이미지 교체 → 가로·세로 mm와 비율 유지 → 회전 순서. ‘비율 유지’ 노출은 새 UI 제안이며 현재 동작과 함께 검토한다.

My Rings는 파일 관리, Create는 페이지에 넣기·크기 조절·배치를 담당한다. 자르기·필터·배경 제거는 확인한 기능에 없으므로 이번 범위에 자동 추가하지 않는다.

### A10. 선택과 공통 조작

- 대상이 없으면 짧은 선택 안내만 표시한다.
- 단일 선택은 대상 종류의 설정, 같은 종류 복수 선택은 공통 설정을 표시한다.
- 여러 종류 혼합 선택은 적용 가능한 색상 등 공통 속성만 표시한다. 관련 없는 설정은 노출하지 않는다.
- 삭제·잠금/해제·그룹/해제는 선택에 맞는 액션으로 제공한다.
- 화면만 회전하는 기능과 실제 요소 회전, 인쇄 방향 변경을 명확히 구분한다.
- 실행 취소/다시 실행이 페이지 구조 변경과 편집에 어떻게 적용되는지 정의한다.

### A11. 페이지 관리

#### 사용자 요청

- 추가·삭제·메뉴를 각 페이지에 둔다.
- 미리캔버스·캔바를 화면 구성의 참고 대상으로 삼는다.
- 별도 영역으로 과도하게 분리하지 않고 단순하게 유지한다.

#### 설계 제안

- 페이지 위: 이름·번호, 복제 버튼, 더보기 메뉴.
- 페이지 아래 또는 페이지 사이: ‘＋ 페이지 추가’.
- 더보기: 여러 장 복제, 내 템플릿으로 저장, 위·아래로 이동, 삭제.
- 삭제 후 실행 취소 제공.
- 페이지 순서 변경과 여러 페이지 선택을 위한 ‘페이지 한눈에 보기’는 필요할 때 연다.
- 도구와 상단 액션은 고정하고 중앙 페이지 영역을 스크롤한다.

미정: 상시 표시와 마우스 접근 시 표시의 구분, 모바일 조작, 여러 페이지 선택 방식, 긴 작업에서의 탐색 방식.

### A12. 여러 장 복제

#### 사용자 요청

반복되는 페이지가 많으므로 n개를 입력해 자동으로 복사한다. 기본계획의 기존 템플릿·반복 페이지 내용은 이 절과 자동필드·템플릿 저장·단면/양면 절로 통합해 관리한다.

#### 설계 제안

- 입력값은 ‘추가할 페이지 수’로 표현한다.
- 예: 10 입력 시 ‘현재 페이지 뒤에 10페이지를 추가합니다’ 표시.
- 원본은 유지하고 뒤에 복사본을 삽입한다.
- 앞뒤가 묶인 구성은 ‘세트 수’로 입력한다.
- 복제는 내용 그대로 복사하고, 날짜 자동 진행은 별도 생성 기능으로 구분한다.

미정: 최대 개수, 여러 페이지 선택 시 복제 단위, 복제본 간 공통 디자인 연결 여부, 대량 생성 시 성능과 진행 표시.

### A13. 공통 색상 팔레트

#### 사용자 요청

- 색상을 좌측 하단에 따로 배치해 관리한다. 위치와 접근 방식은 포토샵을 참고한다.
- 기본 컬러는 블랙 계열로 둔다.
- 포인트 컬러를 원하는 만큼 추가한다.
- 포인트 컬러는 A·B·C 같은 식으로 구분한다.
- 색상 변경을 쉽게 한다.

#### 설계 제안: 작업 팔레트와 연결 색상

```text
작업 색상
● 기본   ● A   ● B   ● C   ＋
```

- 기본색: 글자·선에 사용할 검정 또는 차콜.
- 포인트 A/B/C: 사용자가 추가·편집하는 색상.
- 요소는 실제 색상값 대신 기본/A/B 등의 색상 역할에 연결할 수 있다.
- A의 색을 바꾸면 현재 작업에서 A에 연결된 요소가 함께 바뀐다.
- 색상에 ‘제목’, ‘체크박스’ 등의 별명을 붙이는 방식을 검토한다.
- 팔레트는 현재 작업 단위로 관리한다. 다른 저장 작업을 자동 변경하지 않는다.

#### 적용과 편집 구분

| 동작 | 제안 결과 |
|---|---|
| 요소를 선택한 뒤 A 클릭 | 선택 요소에 A 연결 |
| A의 색상 편집 열기 | 현재 작업에서 A를 사용하는 요소의 색 변경 |
| 개별 색상 지정 | 해당 요소를 공통 팔레트와 독립적으로 관리 |

전체 변경 시 ‘A · 12개 페이지에서 사용 중’처럼 영향 범위를 표시하는 방식을 검토한다. 색상은 색만으로 구별하지 않고 기본/A/B 등의 문자도 함께 표시한다.

#### 템플릿과의 관계 — 검토안

템플릿을 추가할 때 현재 작업의 기본/A/B에 연결하면 여러 양식의 색감을 통일하기 쉽다. 다만 서로 다른 템플릿에서 A의 의미가 다를 수 있으므로 자동 연결을 확정하기 전에 규칙을 정해야 한다.

미정:

- 기본색도 변경할 수 있는지, 기본색의 초기값.
- 사용 중인 포인트 색상 삭제 시 다른 색상으로 대체하는 방식.
- 많은 색상이 생겼을 때 펼침·스크롤 방식.
- 새 요소를 만들 때 적용할 활성 색상.
- 선·채움·글자 등 여러 색상 속성을 가진 요소의 적용 대상.
- 기존 직접 지정 색상을 팔레트에 연결하는 방법.
- 템플릿의 원래 색 유지와 현재 작업 색 적용 선택.
- 특정 페이지에서만 A를 다른 색으로 쓰고 싶은 경우의 처리.
- 전체 변경 미리보기와 실행 취소 범위.

### A14. 인쇄 준비 — Create의 후반 액션

#### 설계 제안

템플릿·제작 화면에서는 앞뒤 페이지의 논리적인 짝을 관리하고, 인쇄 준비에서는 프린터의 단면·양면 출력 조건을 설정한다.

- 앞뒤 한 쌍의 복제·이동 시 짝을 유지한다.
- 필요할 때 앞뒤를 나란히 볼 수 있는 보기 방식을 검토한다.
- 인쇄 용지에 여러 속지를 배치해도 제작 화면의 페이지 순서는 유지한다.
- 출력 조건: 용지 크기, 양면, 용지 위 배치, 재단선, PDF 내보내기.
- 인쇄 준비에서 내용 수정 시 해당 페이지의 제작 화면으로 복귀한다.

미정: 단면 페이지와 양면 세트를 섞을 때 빈 뒷면 처리, 홀수 페이지 출력, 수동 양면 인쇄, 짝의 일부 삭제 시 처리.

설정 순서는 출력 범위 → 용지 크기·방향 → 단면/양면 → 배치 미리보기 → 재단선 → PDF로 제안한다. 배치 간격·자동 회전·정렬·재단 후 쌓는 순서·무더기·검증 눈금은 필요에 따라 고급 설정에 둔다. 실제 크기 출력 안내와 인쇄 불가 영역을 보존한다. 출력 칸 배정과 내용 편집의 역할은 분리하며, 여러 저장 작업을 한 용지에 조합하는 기존 활용을 새 페이지 구조에서 어떻게 보존할지 추가 검토한다.

### A15. 검토 순서와 구현 전 확인

1. 화면 스케치에서 왼쪽 삽입 패널과 상단 꾸미기 바의 역할 분리 검토.
2. 오토필드의 종류 선택·형식 예시·날짜 연결 UI 검토.
2. 공통 글자 패널: 굵게 제거 범위, pt·mm, 줄간격·자간 검토.
3. 나머지 도구의 세부 항목 순서와 기본/고급 구분 검토.
4. 페이지 생성·복제·템플릿·팔레트의 공통 수정과 개별 수정 경계 확정.
5. 기존 데이터의 외형 보존, 자간과 단위의 화면/PDF 일치, 저장 후 재열기를 구현 검증 항목으로 지정.

이번 작업은 문서 계획이며 UI 구현, 데이터 변환, 기능 삭제를 실행하지 않는다.

## B. My Rings — 현재 합의와 연결 범위

내 작업 / 내 템플릿 / 이미지 / 글꼴을 관리한다. 이번에는 Create와 연결되는 범위만 기록하며 전체 화면 상세 설계는 후속 논의한다.

### B1. 사용자 요청

이미지와 글꼴 파일 관리도 My Rings 메뉴에 포함한다.

### B2. 설계 제안

- 내 작업 / 내 템플릿 / 이미지 / 글꼴을 관리하되 별도 메인 메뉴는 추가하지 않는다.
- 이미지 파일 목록과 미리보기를 확인하고 편집기에서 페이지에 삽입할 수 있게 한다.
- 등록한 글꼴과 미리보기를 확인하고 편집기의 글꼴 선택에서 사용할 수 있게 한다.
- 편집 중 자료를 사용할 때마다 My Rings로 이동하지 않고 해당 도구에서 바로 선택할 수 있게 한다.

미정: 등록·이름 변경·삭제 UI, 파일 형식·용량, 중복 처리, 사용 중인 파일 삭제가 기존 작업에 미치는 영향, 저장 위치와 동기화. My Rings에 포함한다는 합의가 클라우드 업로드나 계정 기능 도입까지 의미하지는 않는다.

## C. Learn — 후속 설계

현재 방향은 시작 안내, 사용 가이드, 규격·종이·바인더 참고 자료, 인쇄 안내를 담는 것이다. 세부 탐색 구조·콘텐츠는 아직 확정하지 않았다. 이번 Create 분석 범위에서 임의로 확대하지 않는다.
