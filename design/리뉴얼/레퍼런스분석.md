# 레퍼런스 분석 — Canva · 미리캔버스

작성일: 2026-09-27  
상태: 사용자 검토용  
관련 문서: [기본계획.md](./기본계획.md) · [세부계획.md](./세부계획.md) · [디자인.md](./디자인.md)

사용자 계정으로 로그인한 상태에서 두 서비스의 작업 목록과 편집기를 직접 확인했다. Canva는 148×210mm 빈 디자인, 미리캔버스는 210×297mm 빈 디자인으로 편집기를 열었다. 데스크톱 폭 약 800px 화면 기준이며, 넓은 화면에서는 배치가 조금 다를 수 있다.

## 1. 작업 목록

| | Canva | 미리캔버스 |
|---|---|---|
| 메뉴 이름 | 프로젝트 | 워크스페이스 → 내 드라이브 |
| 목록 구성 | 모든 프로젝트 / 최근 디자인 / 내 프로젝트 / 공유 / 오프라인 / 링크 관리 | 내 드라이브 / 팀 드라이브 / 공유받은 디자인 / 즐겨찾기 / 휴지통 |
| 보관하는 것 | 디자인 · 폴더 · 업로드한 이미지·동영상·파일 | 폴더 · 디자인 · 디자인 요소 |
| 정리 방법 | 폴더, 별표, 유형·카테고리·수정 날짜 필터 | 폴더, 즐겨찾기, 탭(전체/폴더/디자인/디자인 요소), 정렬 |
| 템플릿 | **개인용 ‘내 템플릿’이 없다.** 브랜드 템플릿은 유료·팀 기능 | **‘내 템플릿’이 없다.** 대신 ‘디자인 요소’(재사용 조각)를 보관 |
| 휴지통 | 있음 (30일 후 삭제) | 있음 |

- 두 서비스 모두 **모든 결과물이 ‘디자인’ 하나**이고 폴더로 정리한다. 한 장짜리와 여러 장짜리를 구분하지 않는다.
- 미리캔버스는 썸네일에 **페이지 수 배지**(예: 14)를 붙인다.
- 업로드한 이미지·파일도 같은 목록에서 관리한다(Canva는 유형 필터로 구분).

## 2. 새로 만들기

| | Canva | 미리캔버스 |
|---|---|---|
| 진입 | 왼쪽 ‘+ 만들기’ | 상단 ‘새 디자인 만들기’ |
| 창 구성 | 왼쪽 분류 / 검색 / 인기 크기 카드 | 왼쪽 분류 / 검색 / 분류별 크기 카드 |
| 직접 크기 | ‘맞춤형 크기’: 가로·세로·단위(px·in·**mm**·cm), 비율 잠금 | ‘직접 입력’ |
| 이후 | 새 탭에 편집기 | 편집기 창이 열리고 ‘무엇을 만들어야 하나요?’ 창이 한 번 더 뜸 |

Rings는 크기가 이미 사용자 기본 규격으로 정해져 있으므로 이 단계 자체를 줄일 수 있다.

## 3. 편집기

### 3.1 공통 뼈대

두 서비스 모두 같다.

```text
┌ 상단 바: 홈 · 파일 · 되돌리기 · 저장 상태 · 제목 · 크기 ·······  공유 · 다운로드 ┐
│ 아이콘 레일 │ 넓은 패널 │        캔버스 (페이지가 세로로 이어짐)                │
│             │           │        + 페이지 추가                                  │
└ 하단 바: ····························  확대 비율 · 페이지 n/n · 한눈에 보기 ┘
```

- 아이콘 레일: 템플릿 · 요소 · 텍스트 · 업로드 · **프로젝트** · (앱·AI 등). 누르면 옆 패널 내용이 바뀐다.
- 편집기 안의 ‘프로젝트’ 패널에서 **내 다른 디자인을 열어보고 가져올 수 있다.**
- 저장 상태는 구름 아이콘으로 상단에 보인다.

### 3.2 선택한 요소의 꾸미기 — 두 서비스가 다르다

| | Canva | 미리캔버스 |
|---|---|---|
| 위치 | **캔버스 위 가로 막대** | **왼쪽 패널이 ‘속성’으로 바뀜** |
| 글자 선택 시 | 글꼴 · 크기(− 44 +) · 색 · 굵게 · 기울임 · 정렬 · 목록 · 간격 · 투명도 · … | 글꼴 · 크기(− 57.4 +) · 굵게 · 기울임 · 밑줄 · 정렬 · 목록 · 글자색 · 배경색 / 외곽선 · 그림자 · 곡선 · 세로쓰기 스위치 |
| 세부 설정 | ‘간격’ 팝오버: 글자 간격·줄 간격을 슬라이더+숫자로 함께 | 패널 안에서 접고 펼치기 |
| 좁은 화면 | 넘치는 항목은 ‘…’ 둘째 줄로 | 패널이 세로로 길어짐 |
| 요소 바로 위 | 작은 메뉴: 댓글 · 잠금 · … | 작은 메뉴: 복제 · 삭제 · 잠금 · … |
| 요소 바로 아래 | 회전 · 이동 핸들 | 회전 · 이동 핸들 |

- **Canva 방식**: 넣기 패널과 꾸미기가 동시에 보인다. 대신 가로 공간이 좁아 라벨 없이 아이콘 위주다.
- **미리캔버스 방식**: 라벨과 숫자 칸을 넉넉히 둘 수 있다. 대신 요소를 선택하는 동안 넣기 패널이 사라진다.

### 3.3 색상

- Canva는 색 버튼을 누르면 **왼쪽 패널이 색 선택 화면으로 바뀐다.**
- 맨 위에 **‘이 디자인에 사용된 색상’**이 자동으로 모이고, 그 아래 브랜드 키트(유료)와 기본 색이 있다.
- 사용자가 따로 팔레트를 만들지 않아도 쓴 색이 모인다는 점이 Rings의 작업 팔레트와 비교할 거리다.

### 3.4 페이지 관리

| | Canva | 미리캔버스 |
|---|---|---|
| 페이지 위 | ‘페이지 2 - 제목 추가’ + 위로 · 아래로 · 숨기기 · 복제 · 삭제 · 추가 | ‘1 페이지 - 제목 입력’ + 메모 · 위로 · 아래로 · 추가 · 복제 · 삭제 |
| 페이지 아래 | ‘+ 페이지 추가’ 긴 버튼, 옆 ▾로 다른 종류 페이지 추가 | ‘+ 페이지 추가’ 긴 버튼 |
| 한눈에 보기 | 하단 격자 버튼 → 모든 페이지 격자, 여러 개 선택·순서 변경·일괄 삭제 | 하단 페이지 보기 버튼 |
| 썸네일 줄 | 하단 ‘페이지’ 버튼으로 켜고 끔 | — |

두 서비스 모두 **페이지 목록을 상시 펼쳐두지 않는다.** 세부계획 A11의 제안과 같다.

### 3.5 자동으로 채워지는 글자

Canva는 텍스트 패널 안에 **‘동적 텍스트 — 페이지 번호’**를 둔다. 자동 채움 글자를 별도 도구가 아니라 텍스트 도구 안의 한 항목으로 다룬다.

## 4. Rings에 적용할 것 — 제안

1. **Library는 한 목록 + 폴더.** ‘내 템플릿’을 따로 두지 않는다. 두 서비스 모두 이 구조다. (사용자 제안과 같음)
2. **템플릿 대신 ‘다른 작업에서 페이지 가져오기’.** 편집기 레일에 Library 패널을 두고, 저장한 작업을 열어 원하는 페이지를 현재 작업에 넣는다.
3. **페이지 위 관리 버튼 + 아래 ‘+ 페이지 추가’.** 추가 버튼의 ▾에 빈 페이지 / 다른 작업에서 / 날짜로 만들기를 둔다(세부계획 A0 아이디어 4).
4. **한눈에 보기는 하단 버튼으로.** 순서 변경·여러 개 선택·여러 장 복제를 여기서 한다.
5. **상단 저장 상태 표시.**
6. **Library 목록 썸네일에 페이지 수 표시.**

## 5. 결정할 것

**꾸미기 설정을 어디에 둘까 — Canva식(위 막대) / 미리캔버스식(왼쪽 패널)**

Rings는 두 서비스보다 숫자 설정이 많다(mm 두께, 자간·줄간격 mm, 자동필드의 날짜 연결 등). 세부계획 A3은 ‘라벨을 항상 표시한다’고 정했는데, 위 막대는 라벨을 둘 공간이 좁다.

- 위 막대(현재 세부계획 A0): 넣기와 꾸미기가 동시에 보인다. 자주 쓰는 것만 막대에, 나머지는 팝오버로.
- 왼쪽 패널: 라벨·숫자 칸이 넉넉하다. 선택 중에는 넣기 패널이 가려진다.
