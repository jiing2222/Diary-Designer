# Rings 디자인 계획

작성일: 2026-09-27  
상태: 사용자 검토용 · 최종 시안 전  
관련 문서: [기본계획.md](./기본계획.md) · [세부계획.md](./세부계획.md)

제품의 시각적 방향을 관리한다. 기능 동작과 설정 항목 순서는 세부계획에서 다룬다.

## 1. 전체 콘셉트

### 합의된 콘셉트

**Blue Editorial Stationery / Vintage Print + Soft UI + Saturn Motif**

- 밝고 친근한 에디토리얼·문구 디자인.
- 빈티지 에디토리얼 일러스트, 파스텔, 얇은 선, 종이 인쇄물 같은 질감.
- 블루 비중을 높이고, 차콜·브라운과 크림 배경을 조합한다.
- 버터 옐로는 필요한 곳에 작은 포인트로 사용한다.
- 키치하지만 유치하지 않게, 여백은 넉넉하게 구성한다.
- 실제 편집기는 명확성과 사용성을 우선한다.

### 결정 (2026-10-01) — 색과 선 (3차)

1차(크림+파우더블루)·2차(팬톤 차트: Transparent Yellow 바탕)를 거쳐 정했다. 노란 바탕은 빼고, 진하거나 옅은 극단을 피해 **중간 농도**로 맞췄다. 참고: `참고이미지/popo-letter.webp`, `블루브라운차콜-코어.webp`, `팬톤-컬러차트.webp`.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#FBFAF7` | 앱 바탕 (거의 흰색) |
| 면 그레이지 | `#F2F0EB` | 레일·패널·막대 |
| 눌림·호버 | `#E7E3DB` | 면 위의 버튼에 올렸을 때 |
| 글자 | `#2E2723` | 본문 (브라운 기운 검정) |

| 브라운 | `#6B4E3D` | 주 버튼(Print), 고른 도구·항목의 진한 알약, 로고 선 |
| 브라운 옅게 | `#EEE5DD` | 다이어리 칩 등 |
| 블루 | `#8EA8C6` | AutoField 선택 테두리 등 선택 표시 |
| 블루 옅게 | `#E2E9F1` | 하위 항목 선택 알약, Select 활성 |
| 블루 진하게 | `#4F6E94` | 링크, 강조 글자 |
| 버터 | `#EDD99A` | 아주 작은 포인트(토성 몸체 등) |
| 구분선 | `#E3DFD7` | 면 안의 구분선 |

- 결정 (2026-10-01): **바탕과 면을 바꿨다** — 바탕이 거의 흰색, 레일·패널이 그레이지. 흰 속지가 거의 흰 바탕 위에 놓이므로 속지 가장자리에 아주 옅은 그림자나 구분선(`#E3DFD7`)을 둬서 종이 경계가 보이게 한다.
- **테두리 없음.** 레일·패널·막대는 면 색 차이와 둥근 모서리로만 구분한다(`참고이미지/깔끔한-사이드메뉴.png`). 선 일러스트(토성 로고 등)는 1px 브라운 선을 유지한다.
- **속지 종이는 늘 흰색.** 앱 색이 속지에 섞이지 않는다.
- **AutoField 선택 표시는 블루 테두리**, 일반 글자 선택과 구별한다(세부계획 A4.6).
- 넓은 장식 면(토성 홈·Learn)에 쓸 블루의 넓은 면 버전은 시안에서 정한다.
- 레트로 OS 모티프는 보류(`참고이미지/레트로OS-보드.webp`).
- 값은 시안의 출발점이며 실제 화면에서 조정할 수 있다.

### 결정 (2026-10-01) — 글꼴

| 역할 | 글꼴 | 쓰는 곳 |
|---|---|---|
| 제목용 영문 | **Jost** (푸투라 계열, POPO 제호와 같은 결) | 로고 ‘Rings’, 메뉴 이름(Create·Library·Learn·Print), 홈의 큰 제목 |

- 모두 무료(OFL) 글꼴이라 웹앱에 넣을 수 있다.
- 편집기의 작은 글자는 전부 Pretendard. 제목 글꼴은 크게 쓰이는 곳에서만 분위기를 낸다.
- 이 글꼴들은 **앱 화면용**이다. 사용자가 속지에 쓰는 글꼴(Library → Fonts)과는 별개.

### 결정 (2026-10-01) — 아이콘

- 레일은 **아이콘만**, 마우스를 올리면 이름.
- AutoField 아이콘은 **`{ }`**(채워지는 칸).
- Select 커서는 **모서리가 둥근 화살표**로 귀엽게(`참고이미지/둥근-커서.png`). 같은 계열로 `+`·`−` 변형을 다른 커서 상태에 쓸 수 있다.

## 2. 토성 홈

- 행성 본체: Create.
- 서로 다른 두 개의 링: 각각 Library와 Learn.
- 하나의 링을 위아래로 나눈 구조가 아니라 실제로 분리된 두 개의 링이다.
- 별·별자리 연결 애니메이션은 장식으로 사용한다.
- 설계 제안: 각 목적지의 이름을 읽을 수 있게 표시하고, 내부 화면에서는 일반적인 메뉴로 이동할 수 있게 한다.

### 결정 (2026-10-01) — 토성 홈 그림 (4차 스케치)

- **기하학적 선 그림으로 시작한다**(원·타원). 손맛 있는 일러스트는 나중에 얹는다 — AI로 스케치를 뽑고, 벡터(SVG)로 정리해 1px 브라운 선으로 통일한 뒤 넣는다. 쓰는 AI 서비스의 상업적 사용 조건을 확인한다.
- **행성은 버터 노랑**(`#EDD99A`)에 1px 브라운 외곽선. (브라운 행성은 시도했다가 뺐다.) **별도 버터 노랑.**
- 결정 (2026-10-06): **홈 바탕도 앱 바탕과 같은 아이보리**(`#FBFAF7`). 블루 장식 면을 깔지 않는다 — 홈에서 편집기로 넘어갈 때 화면이 이어져 보이게. 파우더블루 넓은 면 계획(장식 면)은 쓰지 않는다.
- **링은 두꺼운 띠, 두 링 모두 같은 블루 계열.** 차이는 진하기와 넓이로: 안쪽 링(Learn)은 진하고 좁게(약 10px), 바깥 링(Library)은 연하고 넓게(약 20px).
- **행성도 자전한다.** 행성 안의 가로 줄무늬(구름 띠, 진하고 옅은 노랑)가 옆으로 흘러 도는 느낌을 준다. 예전 스케치의 가운데 점선은 이 줄무늬를 선으로 흉내낸 것이었고, 띠로 바꿨다.
- **링이 실제처럼 돈다.** 띠 위의 작은 입자 점이 링을 따라 흐르고, **안쪽 링이 더 빠르다**(실제 토성처럼 안쪽 궤도가 빠름). 별은 천천히 반짝인다. 움직임 줄이기 설정이면 멈춘다.
- **글자는 평소에 보이지 않는다.** 마우스를 올리면(또는 키보드로 고르면) 그 링·행성의 색이 진해지고 **알약 모양 이름표**가 나타난다 — 행성은 Create, 링은 Learn·Library.
  - 링을 따라 보이지 않는 두꺼운 ‘누르는 영역’을 깐다.
  - 터치 기기는 그때 가서 정한다.
- **로고는 왼쪽 위**(지금 자리 유지). 로고 아래에 **‘make your own system’**을 작게 둔다.
- **홈은 비워둔다.** 최근 작업은 Library에서 본다.

참고: `참고이미지/ChatGPT-사이드바.webp`.

## 3. 레퍼런스의 역할

미리캔버스와 캔바는 사용자가 제시한 화면 구성의 참고 대상이다. 템플릿을 통한 시작, 여러 페이지를 세로로 편집하는 경험, 페이지 가까이의 관리 기능을 Rings에 맞게 적용한다. 본 문서는 해당 서비스의 최신 화면을 실측하거나 그대로 재현한 명세가 아니다.

## 4. 편집기 시각 표현

- 좌측 설정의 제목·라벨·입력칸·아이콘·간격·선택 표시를 통일한다.
- 종이 질감과 장식은 글자 가독성과 정확한 편집을 방해하지 않는 범위에서 사용한다.
- 화면을 단순하게 유지하고 세부 기능은 필요할 때 펼친다.
- 앱의 블루 중심 브랜드 색상과 사용자가 속지에 사용하는 작업 팔레트는 별개다. 속지의 기본색·포인트색은 사용자가 구성한다.
- 작업 팔레트의 적용·변경 규칙은 세부계획에서 관리한다.

상황별 상단 도구막대를 두고 왼쪽은 자료·내용 선택에 집중하는 화면 구성을 검토한다. 패널·바·팝오버 모두 같은 라벨, 입력 높이, 선택 표시를 사용한다. 구체적인 도구 배치와 새 아이디어는 세부계획 A0에서 관리한다.

## 5. 미정 사항

- 최종 색상값과 사용 비율.
- UI 글꼴·크기·굵기와 제목 체계.
- 토성과 두 링의 형태·클릭 영역·작은 화면 배치.
- 질감 강도, 아이콘 스타일, 애니메이션 속도와 강도.
- 버튼·입력칸·패널의 치수와 상태별 표현.
- 자동필드를 선택했을 때의 테두리 색. 일반 텍스트 상자의 선택 색과 확실히 구별되어야 한다(세부계획 A4.6).

이 문서는 시각적 방향의 기준이며 완성된 시안이나 구현 명세가 아니다.
