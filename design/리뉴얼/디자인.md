# Rings 디자인 계획

작성일: 2026-09-27  
상태: 사용자 검토용 · 최종 시안 전  
관련 문서: [기본계획.md](./기본계획.md) · [세부계획.md](./세부계획.md)

제품의 시각적 방향을 관리한다. 기능 동작과 설정 항목 순서는 세부계획에서 다룬다.

## 1. 전체 콘셉트

### 합의된 콘셉트

**Blue Editorial Stationery / Vintage Print + Soft UI + Saturn Motif**

- 밝고 친근한 에디토리얼·문구 디자인.
- 빈티지 에디토리얼 일러스트, 파스텔, 얇은 선, 종이 인쇄물 같은 질감.
- 블루 비중을 높이고, 차콜·브라운과 크림 배경을 조합한다.
- 버터 옐로는 필요한 곳에 작은 포인트로 사용한다.
- 키치하지만 유치하지 않게, 여백은 넉넉하게 구성한다.
- 실제 편집기는 명확성과 사용성을 우선한다.

## 2. 토성 홈

- 행성 본체: Create.
- 서로 다른 두 개의 링: 각각 My Rings와 Learn.
- 하나의 링을 위아래로 나눈 구조가 아니라 실제로 분리된 두 개의 링이다.
- 별·별자리 연결 애니메이션은 장식으로 사용한다.
- 설계 제안: 각 목적지의 이름을 읽을 수 있게 표시하고, 내부 화면에서는 일반적인 메뉴로 이동할 수 있게 한다.

## 3. 레퍼런스의 역할

미리캔버스와 캔바는 사용자가 제시한 화면 구성의 참고 대상이다. 템플릿을 통한 시작, 여러 페이지를 세로로 편집하는 경험, 페이지 가까이의 관리 기능을 Rings에 맞게 적용한다. 본 문서는 해당 서비스의 최신 화면을 실측하거나 그대로 재현한 명세가 아니다.

## 4. 편집기 시각 표현

- 좌측 설정의 제목·라벨·입력칸·아이콘·간격·선택 표시를 통일한다.
- 종이 질감과 장식은 글자 가독성과 정확한 편집을 방해하지 않는 범위에서 사용한다.
- 화면을 단순하게 유지하고 세부 기능은 필요할 때 펼친다.
- 앱의 블루 중심 브랜드 색상과 사용자가 속지에 사용하는 작업 팔레트는 별개다. 속지의 기본색·포인트색은 사용자가 구성한다.
- 작업 팔레트의 적용·변경 규칙은 세부계획에서 관리한다.

상황별 상단 도구막대를 두고 왼쪽은 자료·내용 선택에 집중하는 화면 구성을 검토한다. 패널·바·팝오버 모두 같은 라벨, 입력 높이, 선택 표시를 사용한다. 구체적인 도구 배치와 새 아이디어는 세부계획 A0에서 관리한다.

## 5. 미정 사항

- 최종 색상값과 사용 비율.
- UI 글꼴·크기·굵기와 제목 체계.
- 토성과 두 링의 형태·클릭 영역·작은 화면 배치.
- 질감 강도, 아이콘 스타일, 애니메이션 속도와 강도.
- 버튼·입력칸·패널의 치수와 상태별 표현.
- 자동필드를 선택했을 때의 테두리 색. 일반 텍스트 상자의 선택 색과 확실히 구별되어야 한다(세부계획 A4.6).

이 문서는 시각적 방향의 기준이며 완성된 시안이나 구현 명세가 아니다.
