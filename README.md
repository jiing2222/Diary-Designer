# Rings — System Diary Designer

다이어리 속지를 여러 페이지로 만들고 실제 크기의 PDF로 출력하는 웹앱.
저장소: https://github.com/jiing2222/Diary-Designer

## 실행과 검증

```bash
npm run dev
npm test
npm run build
npm --prefix app run lint
```

개발 화면은 http://localhost:5173 에서 열린다. 타입 검사는 `npm run build`로 한다.
solution 스타일 tsconfig라 `tsc --noEmit`만으로는 앱 전체를 검사하지 않는다.

## 저장과 출력

새 버전은 `rings-v2`에 작업마다 따로 저장한다. 처음 열 때 기존 저장소의 작업을 복사하며
기존 양식 원본은 바꾸지 않는다. 글꼴·이미지도 `rings-v2`에 id별로 따로 보관한다.
옛 파일 캐시는 읽어서 복사하며 쓰거나 지우지 않는다. 이름이 같은 파일도 별개로 유지한다.
목록에서 뺀 파일은 작업·글자 설정·실행 취소·복사 기록이 필요로 하는 동안 보존한다.
파일이 없어도 목록 정보를 유지해 누락을 알리고, 같은 파일을 다시 올리면 연결을 복구한다.
색상 미리보기는 확정하기 전까지 작업에 저장하지 않는다. 저장 실패 시 다시 저장할 수 있다.

편집용 도트·타공 안내와 실제 인쇄할 표시는 다르다. Print의 미리보기에서 출력 모습을 확인하고,
PDF를 인쇄할 때는 **실제 크기 / 100%**를 고른다. 50mm 검증 눈금으로 치수를 확인할 수 있다.
새 글자 효과·타공 표시 등의 실물 인쇄 검증은 진행상황.md에 별도로 남긴다.

## 코드 구조

- `core/`: mm 기반 모델·치수·날짜·색·배치 계산. 화면과 PDF에 의존하지 않는다.
- `store.ts`: 작업·탭·편집 상태와 실행 취소.
- `storage/`, `ui/persist.ts`: 브라우저 저장소, 이전 데이터 복사, 자동 저장 결과.
- `fonts/`, `images/`: 파일 등록·캐시와 공통 글자 측정.
- `ui/`: React·SVG 편집기와 Print 미리보기.
- `pdf/`: 같은 모델을 벡터 PDF로 출력.

문서 좌표·치수는 mm이며 px·pt 변환은 그릴 때 한다. 화면과 PDF의 판단은 core에서 공유한다.
